# Test 5 prompt set

45 prompts across six fact types, written as a template. Swap the placeholders for your own details, then load them into Profound as one tagged prompt group. Each prompt maps to a fact in the [Test 5 fact sheet](test-5-fact-sheet.md).

## How to use

1. **Replace the placeholders.** [Brand] = your product name. [Competitor] = your top 2 or 3 rivals (make one copy of the prompt per competitor). [Plan] = your plan names. [Tool] = integrations buyers ask about most. [Category] = how buyers describe what you sell (for example, "expense software").
2. **Tie each prompt to the fact sheet.** The "Fact it checks" column should point to one line on the fact sheet. Drop any prompt you can't tie to a fact, since it can't be scored.
3. **Keep the wording natural.** Write prompts the way a buyer would type them, not the way your website phrases things. Leave typos and casual phrasing in place.
4. **Mix branded and unbranded.** Most prompts name [Brand] directly. The comparison group also includes unbranded prompts, because that's where engines often get details wrong.
5. **Load as one group in Profound,** tagged "Test 5", and lock it. Don't edit wording during the test, or the re-scores won't be comparable.

The "Cost if wrong" column marks prompts where an error could lose a sale or create a support ticket. Report those first in the readout.
